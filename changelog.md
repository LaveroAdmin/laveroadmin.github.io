# Releases

## V1.0.0

Initial release of LaveroAdmin — a modern, beautiful, and flexible administration panel builder for Laravel.

### Core Highlights
- **Laravel Ecosystem**: Full compatibility with Laravel 10, 11, 12, and upcoming Laravel 13.
- **Pure Modern UI**: 100% Bootstrap 5 and vanilla JavaScript — zero jQuery dependency.
- **Dark Mode**: Built-in full-featured dark mode with system theme detection and instant switcher.
- **Security & 2FA**: Native Two-Factor Authentication (2FA) with TOTP QR codes and backup recovery codes.
- **Command Palette**: Global search and keyboard navigation (`Ctrl+K` / `Cmd+K`).
- **Data Export**: High-performance Excel (XLSX) and CSV exports powered by PhpSpreadsheet.
- **Image Processing**: Modern image manipulation using Intervention Image v4.
- **SPA Navigation**: Seamless, flicker-free PJAX/AJAX page transitions with auto-restored scroll states.

### Complete Extension Suite (14 Official Extensions)
1. **Activity Log (`laveroadmin/activity-log`)**: Comprehensive audit trail and model attribute diffs powered by Spatie Activitylog.
2. **Backup Manager (`laveroadmin/backup`)**: One-click database & file backups management powered by Spatie Backup.
3. **CKEditor 5 (`laveroadmin/ckeditor`)**: Rich WYSIWYG editor integration with image upload support for Model-Form.
4. **Config Manager (`laveroadmin/config`)**: Database-backed dynamic key-value settings management.
5. **Grid Sortable (`laveroadmin/grid-sortable`)**: Drag-and-drop row sorting for Model-Grid with AJAX persistence.
6. **Helpers (`laveroadmin/helpers`)**: Web-based scaffolding for models, controllers, migrations, and routes inspection.
7. **Log Viewer (`laveroadmin/log-viewer`)**: Interactive Laravel log viewer with severity filtering and search.
8. **Marketplace (`laveroadmin/marketplace`)**: Built-in extension store for discovering, installing, updating, and managing extensions.
9. **Media Manager (`laveroadmin/media-manager`)**: Storage disk explorer with Table/Grid views, breadcrumbs, and form mediapicker.
10. **Queue Manager (`laveroadmin/queue-manager`)**: Real-time queue monitor, failed jobs inspector, retry/delete actions, and batch tracking.
11. **Reporter (`laveroadmin/reporter`)**: Automatic exception catching, stack trace inspection, and error reporting dashboard.
12. **Scheduling (`laveroadmin/scheduling`)**: Artisan scheduled tasks (cron jobs) monitor, inspector, and manual runner.
13. **Translations (`laveroadmin/translations`)**: Dual-column localization manager for PHP language files and JSON translations.
14. **WAFU Firewall (`laveroadmin/wafu`)**: Web Application Firewall with SQLi/RCE/Path Traversal detectors, IP blocklists, and live rules inspector.
