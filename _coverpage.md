# LaveroAdmin <small>v1.0</small>

> Modern, beautiful and flexible administration panel builder for Laravel.

- Pure Vanilla JavaScript & Bootstrap 5 (Zero jQuery)
- Full-featured Model Grid, Form, and Show
- Built-in Dark Mode & Command Palette (Ctrl+K)
- Two-Factor Authentication (2FA TOTP)
- Modern Excel / CSV export via PhpSpreadsheet
- Rich ecosystem of extensions & developer tools
